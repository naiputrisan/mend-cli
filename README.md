mend is a command-line tool that applies the edits AI models write — unified diffs, SEARCH/REPLACE blocks, V4A patches and JSON edit calls — to a tree of text files. Matching tolerates drifted whitespace and wrong line numbers at three tiers, and a run changes every file or none of them. The full behaviour contract is SPEC.md in this repository.

## Run it

```sh
node main.ts [--format=NAME] [--check] [--strict] [PATCH]
```
